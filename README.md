# Aula para todos y todas: DUA y PIAR en acción

Recurso Educativo Digital interactivo para el curso autodirigido de Gestión y Cultura de Aula.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

La salida estática se genera en `dist/` y usa rutas relativas, por lo que puede desplegarse en GitHub Pages o Cloudflare Pages.

En Cloudflare Pages usa `npm run build` como comando de compilación y `dist` como directorio de salida.
